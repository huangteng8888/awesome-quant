## 策略说明

### 单策略（7种）
- RSI(30/70): RSI<30买入, RSI>70卖出
- MACD交叉: MACD金叉买入, 死叉卖出
- 布林带: 价格触下轨买入, 触上轨卖出
- 均线交叉: 价格上穿SMA50买入, 下穿卖出
- 趋势追踪: 价格>SMA50且RSI>50且MACD>0时持仓
- RSI+MACD: RSI<40且MACD金叉买入, RSI>60或MACD死叉卖出
- 买入持有: 开盘买入，持有到最后一天

### 组合策略（5种）
- 多数投票(>=2): 5个单策略投票，>=2票即执行
- RSI+MACD共识: RSI和MACD必须同时发出信号
- 布林+RSI均值回归:布林下轨+RSI<40买入，上轨或RSI>65卖出
- 趋势过滤: 只在上涨趋势中做多
- ATR止损+趋势: 趋势入场+ATR 2倍止损
